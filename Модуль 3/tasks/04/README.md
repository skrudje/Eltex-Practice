# Модуль 3 — задание 4

Модель «Производитель–Потребители» на System V:

- разделяемая память — `shmget`, `shmat`, `shmdt`, `shmctl`;
- семафор — `semget`, `semop`, `semctl`;
- несколько независимых процессов-потребителей;
- наборы чисел размещаются в общей памяти как цепочка блоков.

## Структура блока

Перед каждым массивом находятся:

```text
next_offset
count
values...
```

`next_offset` — смещение следующего блока от начала разделяемой памяти.
Для последнего блока `next_offset == 0`.

Используется смещение, а не обычный C-указатель: разные процессы могут
подключить один сегмент разделяемой памяти по разным виртуальным адресам.

Когда потребитель обработал массив, он устанавливает `count = 0`.
Ссылка `next_offset` сохраняется, поэтому цепочка блоков не разрушается.

## Сборка

```bash
make
```

## Запуск

Сначала производитель:

```bash
./shared_list -p
```

Затем в других терминалах можно запустить несколько потребителей:

```bash
./shared_list -c
./shared_list -c
./shared_list -c
```

Производитель заполняет память случайными массивами, затем ждет их обработки.
Потребитель за один проход обрабатывает один необработанный блок, находит min/max,
ставит `count = 0`, освобождает семафор и делает паузу.

## Просмотр IPC

```bash
ipcs -m
ipcs -s
```

## Аварийная очистка

```bash
./shared_list --cleanup
```

или:

```bash
make clean-ipc
```

## Тесты

```bash
make test
```

Интеграционный тест запускает одного производителя и трех потребителей.
