# Модуль 3 — задание 1

Программа создает копии файлов с помощью родительского и дочернего процессов.
Родитель читает исходные файлы и передает данные дочернему процессу, а потомок
создает файлы с суффиксом `.copy`.

## Структура проекта

```text
main.c       — разбор аргументов и выбор режима;
channels.c   — fork, pipe, FIFO, открытие и закрытие каналов;
channels.h   — интерфейс режимов работы;
transfer.c   — протокол передачи, чтение и запись файлов;
transfer.h   — заголовок протокола и объявления функций;
test.sh      — автоматические проверки;
Makefile     — многофайловая сборка.
```

Вспомогательные функции, которые нужны только внутри одного файла, объявлены
как `static`. Благодаря этому они не видны другим модулям.

## Именованные каналы

Для двустороннего обмена создаются два FIFO:

```text
<имя>.data   — передача файлов от родителя к потомку;
<имя>.ready  — сообщение READY от потомка к родителю.
```

После завершения оба FIFO удаляются через `unlink()`.

## Сборка

```bash
make
```

## Запуск с именованными каналами

```bash
printf 'Hello\n' > example.txt
./file_copy -p /tmp/file_channel example.txt
```

## Запуск с неименованными каналами

```bash
./file_copy example.txt
```

## Тесты

```bash
make test
```

## Очистка

```bash
make clean
```
