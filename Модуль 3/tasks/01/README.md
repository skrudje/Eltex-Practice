# Модуль 3 — задание 1

еще не готово, пока только основа для доработки.

## Что уже работает

- разбор списка файлов из аргументов командной строки;
- разбор параметра `-p имя_канала`;
- создание дочернего процесса через `fork()`;
- два неименованных канала для двустороннего обмена;
- сообщение `READY` от дочернего процесса;
- передача заголовка с именем и размером файла;
- передача содержимого блоками по 4096 байтов;
- создание файла `<исходное_имя>.copy`;
- обработка нескольких файлов;
- диагностика отсутствующего файла в `stderr`;
- завершение дочернего процесса и ожидание через `waitpid()`;
- небуферизованный ввод-вывод: `open`, `read`, `write`, `close`;
- базовый тестовый shell-скрипт.

## Что надо доделать

Главный незавершенный пункт — режим именованного канала:

```bash
./file_copy -p /tmp/my_channel file1.txt
```

Сейчас программа распознает этот параметр, но выводит сообщение `TODO`.
Для полноценного двустороннего взаимодействия удобно создать два FIFO на основе
переданного имени, например:

```text
/tmp/my_channel.data
/tmp/my_channel.ready
```

После этого нужно реализовать `mkfifo`, `open` для обоих процессов и удаление
FIFO через `unlink`.
