# Модуль 3 — задание 3

P2P-чат на двух очередях сообщений POSIX.

## Логика

При запуске указывается базовое имя очередей:

```bash
./p2p_chat /my_chat
```

Программа использует две очереди:

- `/my_chat_1`;
- `/my_chat_2`.

Первый процесс создаёт очереди, принимает через очередь `_1` и отправляет через `_2`.
Второй процесс подключается к существующим очередям, отправляет через `_1` и принимает через `_2`.

Приоритет `1` используется для обычных сообщений. Приоритет `10` используется для сообщения о завершении.

## Сборка

```bash
make
```

## Запуск

В первом терминале:

```bash
./p2p_chat /my_chat
```

Во втором терминале:

```bash
./p2p_chat /my_chat
```

Для выхода:

```text
/exit
```

или `Ctrl+C`.

Процесс, создавший очереди, удаляет их после завершения.

## Проверка

```bash
make test
```

## Файлы проекта

- `main.c` — проверка аргументов и запуск чата;
- `queues.c/.h` — создание, открытие, закрытие и удаление очередей;
- `chat.c/.h` — отправка, приём, поток приёма и обработка SIGINT;
- `protocol.h` — размер сообщения и приоритеты;
- `tests.c` — модульные тесты;
- `test.sh` — интеграционная проверка двух процессов.
