# Модуль 3 — задание 2

Модель «Издатель — Брокер — Подписчик» на очереди сообщений System V.

## Сборка

```bash
make
```

## Запуск

В первом терминале запустить брокер:

```bash
./pubsub -b
```

Во втором терминале запустить подписчика на одну или несколько тем:

```bash
./pubsub -s news tech
```

В третьем терминале запустить издателя с темой:

```bash
./pubsub -p news
```

После запуска издателя вводите сообщения построчно. `Ctrl+D` завершает издателя.
`Ctrl+C` в терминале брокера завершает брокер, отправляет `SIGINT` известным
издателям и подписчикам, затем удаляет очередь сообщений.

## Формат сообщений

Все команды брокеру имеют тип сообщения `1`:

```text
subscribe,<pid>,<topic>
unsubscribe,<pid>,<topic>
send,<pid>,<topic>\n<payload>
```

Пересылаемое подписчику сообщение имеет тип, равный PID подписчика.

## Тесты

```bash
make test
```

Проверяются запуск брокера, запрет второго брокера, доставка по теме,
фильтрация другой темы, завершение подписчика через `SIGINT` и удаление очереди.

## Структура

- `main.c` — разбор режима запуска;
- `ipc.c`, `ipc.h` — создание и подключение очереди System V;
- `protocol.c`, `protocol.h` — формат и разбор сообщений;
- `broker.c`, `broker.h` — подписки, рассылка и завершение клиентов;
- `publisher.c`, `publisher.h` — режим издателя;
- `subscriber.c`, `subscriber.h` — режим подписчика;
- `test.sh` — автоматическая проверка.
