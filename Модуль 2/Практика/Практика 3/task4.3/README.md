# Задание 4.3 — телефонная книга на бинарном дереве

Контакты хранятся в бинарном дереве поиска и упорядочиваются по фамилии,
имени и отчеству. После каждых пяти изменений дерево автоматически
балансируется.

## Сборка

```bash
make
```

## Запуск

```bash
make run
```

## Автотесты

```bash
make test
```

## Очистка сборки

```bash
make clean
```

Контакты сохраняются в файл `contacts.dat`. Формат совместим с предыдущими
версиями телефонной книги: сначала записывается количество контактов, затем
структуры `Contact`.

## Наглядный вывод дерева

В главном меню есть пункт `6. Показать дерево`. Он выводит
классическую схему дерева: корень сверху, левый потомок снизу слева, правый —
снизу справа. В узлах показываются только ID контактов. ID совпадает с номером
контакта в алфавитном списке.
