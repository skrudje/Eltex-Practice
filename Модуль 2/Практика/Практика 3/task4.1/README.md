# Задание 4.1 — телефонная книга

Контакты хранятся в двусвязном упорядоченном списке. Сортировка выполняется по фамилии, затем по имени и отчеству.

## Сборка

```bash
make
```

## Запуск

```bash
make run
```

## Автотесты

```bash
make test
```

## Очистка результатов сборки

```bash
make clean
```

Файл `contacts.dat` совместим с версией задания 2.1: сначала хранится количество контактов, затем структуры `Contact`.
