# Задание 4.2 — очередь с приоритетом

Приоритет задаётся числом от 0 до 255. Чем больше число, тем выше приоритет.

Очередь хранится в односвязном списке, упорядоченном по убыванию приоритета.
Сообщения с одинаковым приоритетом обслуживаются в порядке добавления.

## Сборка

```bash
make
```

## Запуск

```bash
make run
```

## Автотесты

```bash
make test
```

## Очистка

```bash
make clean
```

## Основные операции

- добавление сообщения;
- извлечение первого сообщения;
- извлечение сообщения с точным приоритетом;
- извлечение сообщения с приоритетом не ниже заданного;
- генерация случайных сообщений для демонстрации.
