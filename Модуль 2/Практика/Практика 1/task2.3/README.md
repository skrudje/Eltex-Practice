# Задание 2.3

При запуске пользователь выбирает, какие математические операции будут доступны.
Выбранные команды добавляются в динамический массив структур `Operation`.
Каждая структура хранит название операции, символ и указатель на функцию.

## Сборка и запуск

```bash
gcc -std=c11 -Wall -Wextra -Wpedantic main.c calculator.c -o calculator_2_3
./calculator_2_3
```

Или через Makefile:

```bash
make
make run
```
