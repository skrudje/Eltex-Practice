# Задание 6.1 — телефонная книга в статической библиотеке

Проект основан на задании 4.1. Контакты хранятся в двусвязном упорядоченном списке.
Структуры объявлены в `phonebook.h`, а функции работы с телефонной книгой
реализованы в `phonebook.c` и собираются в статическую библиотеку
`libphonebook.a`.

## Состав проекта

- `main.c` — главное меню программы;
- `phonebook.h` — структуры и объявления функций;
- `phonebook.c` — реализация двусвязного упорядоченного списка;
- `tests.c` — автоматические тесты;
- `Makefile` — сборка библиотеки, программы и тестов.

## Полная сборка

```bash
make
```

При сборке сначала создаётся объектный файл:

```bash
gcc -std=c11 -Wall -Wextra -Wpedantic -c phonebook.c -o phonebook.o
```

Затем объектный файл помещается в статическую библиотеку:

```bash
ar rcs libphonebook.a phonebook.o
```

После этого `main.o` связывается с библиотекой:

```bash
gcc main.o -L. -lphonebook -o phonebook
```

## Запуск

```bash
make run
```

или:

```bash
./phonebook
```

## Автотесты

```bash
make test
```

Тесты также связываются с `libphonebook.a`, а не напрямую с `phonebook.c`.

## Просмотр содержимого библиотеки

```bash
make library-info
```

Ожидаемый вывод:

```text
Содержимое статической библиотеки libphonebook.a:
phonebook.o
```

## Очистка

```bash
make clean
```

Файл `contacts.dat` создаётся программой автоматически и не удаляется командой
`make clean`.
