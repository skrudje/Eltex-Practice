# Задание 6.2 — телефонная книга в динамической библиотеке

Проект основан на задании 6.1 и использует телефонную книгу из задания 4.1.
Контакты хранятся в двусвязном упорядоченном списке.

Структуры и объявления функций находятся в `phonebook.h`, а реализация функций
из `phonebook.c` собирается в динамическую библиотеку `libphonebook.so`.
Основная программа и автотесты используют эту библиотеку при запуске.

## Состав проекта

- `main.c` — главное меню программы;
- `phonebook.h` — структуры и объявления функций;
- `phonebook.c` — реализация двусвязного упорядоченного списка;
- `tests.c` — автоматические тесты;
- `Makefile` — сборка библиотеки, программы и тестов.

## Сборка

```bash
make
```

Сначала `phonebook.c` компилируется с параметром `-fPIC`:

```bash
gcc -std=c11 -Wall -Wextra -Wpedantic -fPIC -c phonebook.c -o phonebook.o
```

Затем создаётся динамическая библиотека:

```bash
gcc -shared phonebook.o -o libphonebook.so
```

После этого программа связывается с библиотекой:

```bash
gcc main.o -L. -Wl,-rpath,'$ORIGIN' -lphonebook -o phonebook
```

Параметр `-Wl,-rpath,'$ORIGIN'` сообщает загрузчику, что библиотеку нужно искать
в одной папке с исполняемым файлом. Поэтому перед запуском не требуется вручную
задавать `LD_LIBRARY_PATH`.

## Запуск

```bash
make run
```

или:

```bash
./phonebook
```

Файл `libphonebook.so` должен находиться рядом с исполняемым файлом `phonebook`.

## Автотесты

```bash
make test
```

Тесты также используют `libphonebook.so`, а не компилируют `phonebook.c`
непосредственно в исполняемый файл.

## Проверка подключения библиотеки

```bash
make library-info
```

В выводе `ldd` должна присутствовать строка с `libphonebook.so`.

## Очистка

```bash
make clean
```

Файл `contacts.dat` командой `make clean` не удаляется.
