# Задание 6.3 — калькулятор с подключаемыми функциями

Программа просматривает каталог `operations`, загружает найденные динамические библиотеки `.so` и строит меню из обнаруженных операций.

Каждая библиотека содержит одну функцию:

```c
double operation(double a, double b);
```

Дополнительно библиотека экспортирует название, символ и порядок операции, необходимые для построения меню.

## Структура

```text
main.c             — меню калькулятора
calculator.c/.h    — поиск и загрузка библиотек
operation_api.h    — единый интерфейс подключаемой операции
operations/*.c     — исходники отдельных операций
tests.c            — автотесты
Makefile           — сборка программы и библиотек
```

## Сборка

```bash
make
```

## Запуск

```bash
make run
```

## Автотесты

```bash
make test
```

## Просмотр библиотек

```bash
make library-info
```

## Очистка

```bash
make clean
```

Чтобы добавить новую операцию, достаточно создать ещё один `.c`-файл в каталоге `operations` по образцу существующих и снова выполнить `make`.
