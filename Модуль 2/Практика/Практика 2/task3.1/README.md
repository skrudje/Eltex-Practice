# Модуль 2 — задание 3.1

Программа рассчитывает маску прав доступа к файлу.

Возможности:
- ввод прав в цифровом виде (`755`) или буквенном (`rwxr-xr-x`);
- вывод буквенного, цифрового и 9-битного представления;
- получение прав реального файла через `stat()`;
- изменение текущей маски командами, похожими на `chmod`, без применения к файлу.

Поддерживаются `u`, `g`, `o`, `a`, операции `+`, `-`, `=` и права `r`, `w`, `x`.
Можно вводить несколько модификаторов через запятую: `u+x,g-w,o=r`.

Сборка: `make`
Запуск: `./permissions`
Тесты: `make test`

Для сравнения прав файла: `ls -l -- имя_файла`.
