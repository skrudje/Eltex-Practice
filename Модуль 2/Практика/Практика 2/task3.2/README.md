# Модуль 2 — задание 3.2

Программа имитирует решение при отправке IPv4-пакетов.

Аргументы запуска:
1. IP-адрес шлюза;
2. маска подсети;
3. количество пакетов `N`.

Для случайного IP назначения вычисляется адрес сети через побитовое AND:

`network = ip & mask`

Если сеть назначения совпадает с сетью шлюза, адрес относится к своей подсети.
Иначе пакет считается предназначенным другой сети и должен идти через шлюз.

Сборка: `make`

Запуск:
`./ipv4_sim 192.168.1.1 255.255.255.0 10`

Тесты: `make test`
